# Figures: draft captions and sources

Generated by `python experiments/figures.py` (needs `pip install -e .[figures]`).
Output: `docs/paper/figures/figN_*.pdf` (paper) and `.png` (review).

Conventions used in every figure:

- **Profile colours**, with a marker each: butterfly (blue, circle), loyal-few
  (red, square), transactional (green, triangle), avoidant (yellow, diamond). The
  four hues only reach the colour-vision floor, so the marker or a label always
  identifies the profile as well.
- **The four layers** use one blue ramp, darkest for the inner circle.
- **Error bars** are 95% t-intervals over seeds unless the caption says otherwise.
