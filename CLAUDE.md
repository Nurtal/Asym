# Asym

Mathematical and computational framework for modelling asymmetric interpersonal
relationship dynamics with heterogeneous multi-agent systems (PDMP simulation +
mean-field ODE analysis). Domain glossary: `CONTEXT.md`. Model: `docs/model-spec.md`.
Decisions: `docs/adr/`.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on `Nurtal/Asym` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
